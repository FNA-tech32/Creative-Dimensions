# Creative Dimension

A modern, high-performance website and digital showcase for **Creative Dimension**, a creative digital studio and software engineering practice focused on clean architecture, efficiency, and exceptional user experience.

---

## 🚀 Overview

**Creative Dimension** delivers digital solutions that combine robust engineering with intuitive user experiences. The website showcases foundational engineering projects, technical capabilities, and provides comprehensive direct and alternative communication channels for clients, partners, and collaborators.

---

## ✨ Features

- **Brand Identity**: Cohesive, modern dark-themed interface built specifically for **Creative Dimension**.
- **Featured Projects Showcase**:
  - **CLI Calculator**: High-performance command-line calculator engineered in C.
  - **Ajo Management App**: Rotating savings and credit association management software built in C.
  - **Simple Interest Calculator**: Accurate financial calculation tool with real-time computation.
- **Comprehensive Contact Hub**:
  - Direct message form with interactive asynchronous submission and toast notifications.
  - Form support for alternative contact information (phone number or backup email).
  - Clear presentation of **Primary** and **Alternative** contact channels (emails, phone lines, studio address, and working hours).
- **Responsive & Accessible**: Fully responsive grid and flexbox layout optimized across mobile, tablet, and desktop screens.
- **Zero Heavy Dependencies**: Pure vanilla HTML5, CSS3, and modern JavaScript for lightning-fast load times.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic document structure and accessible metadata.
- **CSS3**: Modern layout with CSS Grid, Flexbox, backdrop-filter blur effects, and smooth scrolling.
- **JavaScript (ES6+)**: Asynchronous fetch form handling, UI feedback animations, and responsive interactions.
- **Formspree**: Contact form endpoint integration.

## 💻 Getting Started

### Prerequisites

All you need is a modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, etc.).

### Local Setup

1. **Clone or Download the Repository**:
   ```bash
   git clone https://github.com/creativedimension/Creative-Dimension.git
   cd Creative-Dimension
   ```

2. **Open in Browser**:
   - Double-click `index.html` to open it in your default web browser, OR
   - Run a lightweight development server:
     ```bash
     # Using Node.js
     npx serve .
     
     # Or using Python (if installed)
     python -m http.server 3000
     ```

3. **Navigate to the Site**:
   - Visit `http://localhost:3000` (or the URL displayed by your local server).
